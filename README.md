# SLS Camera Project

## Purpose

This project workspace is for the SLS camera effort, including:
- modified Xbox 360 camera hardware
- Windows application/source review
- future custom hardware add-ons
- shared analysis and documentation

## Structure

- `analysis/` - project analysis, orientation docs, notes
- `hardware/` - schematics, wiring, photos, hardware notes
- `software/` - source, build notes, software docs
- `docs/` - shared documentation and project planning

## Delegation

- **Hardware Drake** owns hardware review, schematics, add-ons, and electrical feasibility
- **Code Drake** owns source code, build logic, debugging, and implementation work
- **DrakeBot** coordinates the project and cross-domain planning
