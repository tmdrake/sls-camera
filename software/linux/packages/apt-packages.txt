# Seed apt packages for the SLS Linux field app (Ubuntu/Lubuntu x86_64).
#
# Used by:
#   software/linux/scripts/install-apt-deps.sh
#   install-field-app.sh --with-apt-deps
#
# Seeds only — install-apt-deps.sh never blanket-dpkgs recursive debs.
# When a local deb cache is present (firmware vendor/debs or --deb-cache),
# debs are copied into /var/cache/apt/archives and apt installs these seeds
# with --no-download so transitive deps resolve without OR-alternative
# conflicts (see GitHub #2 / #3).
#
# Keep in sync with sls-camera-firmware/packages/apt-packages.txt (firmware
# may omit espeak-ng if TTS is optional there; field app wants it).
#
# Note: Ubuntu 24.04+ uses t64 transition names (libfreenect0.5t64).
# install-apt-deps.sh resolves both t64 and pre-t64 names.
